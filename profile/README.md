# Hi there 👋 this is the home of Community TechAid development 

## 🙋‍♀️ A short introduction

Community TechAid is a grassroots charity in south London whose vision is to end the digital divide.

Our mission is to enable sustainable access to technology and education needed to extend digital inclusion to all.

## 🗂️ What's here

**TaDa — our device-pipeline application**
- [techaid-server](https://github.com/CommunityTechaid/techaid-server) — the backend API (Kotlin, Spring Boot, GraphQL)
- [techaid-dashboard](https://github.com/CommunityTechaid/techaid-dashboard) — the admin dashboard and public device-request forms (Angular)
- [superset](https://github.com/CommunityTechaid/superset) — configuration for our reporting

**Wiping and recording donated devices**
- [CTA-ShredOS](https://github.com/CommunityTechaid/CTA-ShredOS) and [CTA-ShredOS-2026](https://github.com/CommunityTechaid/CTA-ShredOS-2026) — our build of the ShredOS bootable disk eraser
- [HardwareInfo](https://github.com/CommunityTechaid/HardwareInfo) — collects a device's hardware details for TaDa
- [WipeCertificates](https://github.com/CommunityTechaid/WipeCertificates) — generates disk-wipe certificates
- [ZetaDiscUtils](https://github.com/CommunityTechaid/ZetaDiscUtils) — bulk drive health checks and secure erase
- [PXE-Booting](https://github.com/CommunityTechaid/PXE-Booting) — the workshop's network-boot setup

**Setting devices up for their new owners**
- [Windows-Setup](https://github.com/CommunityTechaid/Windows-Setup), [MacOS-Setup](https://github.com/CommunityTechaid/MacOS-Setup), [Linux-ISO](https://github.com/CommunityTechaid/Linux-ISO)

**Workshop infrastructure**
- [CTA-Ansible](https://github.com/CommunityTechaid/CTA-Ansible) — server build playbooks
- [VM-Backups](https://github.com/CommunityTechaid/VM-Backups) — VM backup scripts
